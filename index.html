TaxJS

一个轻量级、链式调用的 JavaScript 工具库，提供 DOM 操作、动画、数组/对象扩展、AJAX 与前端路由能力。

  • 零构建单文件引入，无任何依赖
  • 链式调用DOM 与数组方法均返回自身，可连续书写
  • 一站集成选择器、动画、AJAX、路由开箱即用

本库通过扩展原生原型（Element、NodeList、Array、Object）提供链式 API，请在业务代码之前引入。

快速开始

TaxJS 是单文件库，直接通过 <script> 引入即可，无需构建：

<script src="TaxJS.js"></script>

引入之后即可使用全部能力：

// 选择元素
const box = t('#box');

// 链式操作
t('#box')
  .sty({ background: 'red', width: '100px' })
  .addCls('active')
  .on('click', () => console.log('clicked'))
  .animate('fadein');

// 数组
const arr = [3, 1, 2].backAdd(4).swap(0, 1).uni();

// AJAX
ajax.get('/api/data', (err, res) => {
  if (err) return console.error(err);
  console.log(JSON.parse(res));
});

// 路由
t.router
  .register('/', () => console.log('home'))
  .register('/about', () => console.log('about'))
  .init();

元素选择器 t

t 是一个函数，同时挂载了若干静态方法。

t(selector)

使用 document.querySelectorAll 查询元素。

参数类型说明
selectorstringCSS 选择器

返回值：

  • 匹配 1 个 → 返回该 Element
  • 匹配多个 → 返回 NodeList
  • 无匹配 / 参数非字符串 → 打印错误并返回 null
t('#id');          // 单个元素
t('.item');        // 多个 → NodeList
t('.not-exist');   // null + 控制台错误

t.getByCls(cls)

按类名获取元素（基于 getElementsByClassName）。

返回值：Element（1 个）/ Array（多个）/ []（无匹配）

t.getByCls('card');

t.getById(id)

按 id 获取元素，返回 Element 或 null。

t.getById('app');

t.create(tag, [parent])

创建元素并插入 DOM，返回新建的 Element。

参数类型说明
tagstring标签名
parentElement可选，缺省插入 document.body
 
const div = t.create('div', document.body);
const span = t.create('span'); // 插入 body

DOM 元素方法

以下方法均挂在 Element.prototype 上，标注返回 this 的方法支持链式调用。

.sty(style, [value])

设置样式，支持单个样式或批量对象。返回 this。

el.sty('color', 'red');
el.sty({ color: 'red', fontSize: '14px' });

.html(content)

设置 innerHTML，返回 this。

el.html('<b>Hello</b>');

.text(content)

设置 innerText，返回 this。

el.text('纯文本');

.val([content])

获取或设置 value。有参 → 返回 this；无参 → 返回 value。

el.val('新值');   // 设置，返回 this
el.val();         // 获取，返回字符串

.addCls(cls) / .delCls(cls)

添加 / 删除类名，返回 this。

el.addCls('active');
el.delCls('active');

.getCls(cls)

判断是否包含某类名，返回 boolean。

el.getCls('active'); // true / false

.getClsList()

返回 className 字符串。

el.getClsList(); // "active big"

.attset(att, value) / .attdel(att) / .attget(att)

属性设置 / 删除 / 获取。attset、attdel 返回 this；attget 返回属性值。

el.attset('data-id', '123');
el.attget('data-id'); // "123"
el.attdel('data-id');

.parent()

返回父元素 parentElement。

el.parent();

.child([index])

无参返回 HTMLCollection；有参返回对应子元素，不存在则为 null。

el.child();    // HTMLCollection
el.child(0);   // 第一个子元素
el.child(5);   // 不存在 → null

.brother()

返回除自身外的所有兄弟元素数组。

el.brother(); // [Element, Element, ...]

.on(event, handler, [options])

addEventListener 的封装，返回 this。

el.on('click', e => console.log(e));
el.on('scroll', handler, { passive: true });

NodeList 扩展

nodeList.sty(style, [value])

批量设置样式，行为同 Element.sty，内部遍历每个元素。返回 this（NodeList）。

t('.item').sty('color', 'blue');
t('.item').sty({ margin: '4px' });

动画 animate

el.animate(type, [duration])

参数类型默认说明
typestring—动画类型
durationnumber400时长（毫秒，正数）

支持的动画类型：

类型说明
show / fadein淡入显示
hide / fadeout淡出隐藏（结束后 display:none）
slideup向上滑动收起
slidedown向下滑动展开
toggle根据当前可见状态切换 show / hide
 
el.animate('fadein');
el.animate('slideup', 600);
el.animate('toggle');

同一元素动画进行中再次调用会被跳过（_isAnimating 标志）； 类型非字符串、时长非正数会抛出 Error； 未知类型打印警告并返回。

数学工具 tMa

方法说明示例
tMa.tu(v)向上取整tMa.tu(1.1) → 2
tMa.td(v)向下取整tMa.td(1.9) → 1
tMa.tr(v, p)四舍五入到 p 位小数tMa.tr(3.14159, 2) → 3.14
 
tMa.tu(2.01);      // 3
tMa.td(2.99);      // 2
tMa.tr(1.2345, 2); // 1.23

数组扩展

以下方法挂在 Array.prototype 上，除 uni、findAll 外均返回 this，支持链式调用。

.atg(...arrays)

将多个数组的元素追加到当前数组。

[1].atg([2, 3], [4]); // [1, 2, 3, 4]

独立函数 atg(...arrays)

扁平化合并所有参数，返回新数组。

atg([1, 2], [3], 4); // [1, 2, 3, 4]

.swap(i, j)

交换下标 i、j 的元素，越界则忽略。

[1, 2, 3].swap(0, 2); // [3, 2, 1]

.clear()

清空数组。

arr.clear(); // arr.length === 0

.uni()

去重，返回新数组。

[1, 1, 2].uni(); // [1, 2]

.frontAdd(...items) / .backAdd(...items)

头部 / 尾部添加。

[2].frontAdd(1);   // [1, 2]
[1].backAdd(2, 3); // [1, 2, 3]

.frontDelete() / .backDelete()

删除头部 / 尾部一个元素。

[1, 2].frontDelete(); // [2]
[1, 2].backDelete();  // [1]

.deleteIndex(index)

按下标删除一个元素。

[1, 2, 3].deleteIndex(1); // [1, 3]

.deleteValue(value)

删除所有等于 value 的元素。

[1, 2, 2, 3].deleteValue(2); // [1, 3]

.findAll(value)

查找所有等于 value 的元素位置信息，返回对象。为避免覆盖原生 find，本库使用 findAll。

[1, 2, 2, 3].findAll(2);
// {
//   in: true,
//   firstIndex: 1,
//   index: [1, 2],
//   count: 2,
//   value: 2
// }

.change(index, newValue)

修改指定下标的值。

[1, 2, 3].change(0, 99); // [99, 2, 3]

对象扩展

扩展 Object.prototype 属于反模式，可能污染所有对象。建议仅在个人项目中使用，生产环境请改用独立工具函数。

.get(key)

获取属性值。

({ a: 1 }).get('a'); // 1

.set(key, value)

设置属性并返回 this。

({}).set('a', 1).set('b', 2); // { a: 1, b: 2 }

AJAX

基于 XMLHttpRequest 的简易封装，ajax.xhr 为内部实例。

ajax.get(url, callback)

参数类型说明
urlstring请求地址
callback(err, responseText) => void回调
 
ajax.get('/api/user', (err, res) => {
  if (err) return console.error(err);
  console.log(res);
});

ajax.post(url, data, callback)

发送 JSON 数据，自动设置 Content-Type: application/json。

ajax.post('/api/user', { name: 'Tom' }, (err, res) => {
  if (err) return console.error(err);
  console.log(res);
});

ajax.open(...args) / ajax.send(...args)

直接代理 xhr.open / xhr.send，用于自定义请求。

ajax.xhr.open('PUT', '/api/x', true);
ajax.xhr.setRequestHeader('Content-Type', 'application/json');
ajax.send(JSON.stringify({ a: 1 }));

ajax.xhr

底层 XMLHttpRequest 实例，可直接访问。

ajax.xhr.timeout = 5000;
ajax.xhr.onerror = () => console.error('network error');

路由 t.router

基于 history.pushState 的极简前端路由。

t.router.register(path, handler)

注册路由，返回 this（链式）。

t.router
  .register('/', () => renderHome())
  .register('/about', () => renderAbout())
  .register('/404', () => render404());

t.router.navigate(path, [silent])

导航到指定路径：执行匹配的 handler（无匹配则找 /404，再没有则警告），非 silent 时 history.pushState。返回 this。

t.router.navigate('/about');

t.router.init()

初始化路由：监听 popstate，并导航到当前 location.pathname（silent）。重复调用不会重复绑定。返回 this。

t.router.init();

t.router.destroy()

移除 popstate 监听，重置初始化状态。返回 this。

t.router.destroy();

t.router.routes

路由表对象（{ path: handler }），可直接读取或修改。

console.log(t.router.routes); // { '/': fn, '/about': fn }

注意事项与已知限制

  1. 原型污染 本库扩展了 Element、NodeList、Array、Object 原型。 尤其 Object.prototype.get/set 会影响所有对象，建议生产环境替换为独立函数： 
    const objGet = (o, k) => o[k];
const objSet = (o, k, v) => (o[k] = v, o);
  2. findAll 而非 find 为避免覆盖原生 Array.prototype.find，查找方法命名为 findAll。
  3. 动画实现 使用 setInterval 分步补间，非 requestAnimationFrame；同一元素动画互斥，进行中再次调用会被跳过。
  4. AJAX 基于 XMLHttpRequest，不支持 Promise / async-await，需使用回调；非 200 状态通过 callback(err) 返回 Error。
  5. 路由 精确匹配，不支持动态参数（如 /user/:id）与通配符；navigate 的 silent 参数仅供 popstate 内部使用。
  6. 浏览器兼容 依赖 classList、history.pushState、querySelectorAll、XMLHttpRequest，面向现代浏览器。
  7. 严格模式 已移除隐式全局变量，可在 'use strict' 下运行。
